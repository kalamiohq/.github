Kalamio is a home for writing on the web. Writers get a distraction-free editor, publications and
the tools to grow an audience. Readers get a clean, fast reading experience. The whole platform is
open source under the AGPL-3.0, and it runs at [kalamio.com](https://kalamio.com).

### Contribute

- Start with a [good first issue](https://github.com/kalamiohq/kalamio/labels/good%20first%20issue). New contributors are welcome.
- Read the [contributing guide](https://github.com/kalamiohq/kalamio/blob/main/CONTRIBUTING.md). The whole app runs locally in about five minutes, with no cloud accounts needed.
- Got a pull request merged? Share it on LinkedIn or X and tag us. We like and reshare every contribution post. `#KalamioContributor`

### Community

Ask questions and share ideas in [GitHub Discussions](https://github.com/kalamiohq/kalamio/discussions),
and chat with contributors on [Discord](https://kalamio.com/discord).
